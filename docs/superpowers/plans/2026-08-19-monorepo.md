# dotfiles monorepo 統合 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** dotfiles-linux / dotfiles-mac を dotfiles リポジトリに統合し、単一 flake で linux / wsl / mac を管理する。

**Architecture:** nix/ に統合 flake (homeConfigurations x2 + darwinConfigurations x1)、dotfiles/ に common/linux/mac の 3 ツリー (DotfilesLinker を 2 回実行)、scripts/ に OS 別スクリプトをファイル名サフィックスで同居させる。

**Tech Stack:** Nix flakes, home-manager, nix-darwin, nix-homebrew, DotfilesLinker, bash

**Spec:** docs/superpowers/specs/2026-08-19-monorepo-design.md

## Global Constraints

- コピー元: `/home/tetsuzin/github/dotfiles-linux`, `/home/tetsuzin/github/dotfiles-mac` (ローカル clone、スナップショット取り込み)
- 作業ブランチ: `monorepo`
- コミットメッセージは日本語 (既存の慣習)
- linux は Lix / mac は素の Nix という前提はスクリプトのフックに残す
- flake attr 名は現状維持: `tetsuzin`, `tetsuzin-wsl`, `shion`
- 検証はこの WSL (x86_64-linux) 上で行う。darwin は dry-run / eval まで

- [ ] **Step 3: `scripts/switch.sh` を monorepo 前提に改修**

以下の 3 箇所を変更する。

(a) OS_DIR チェック (`[[ -n "${OS_DIR:-}" ...` の 2 行) とその下の source 部を置き換え:

```bash
[[ "${OS_NAME:-}" == "linux" || "${OS_NAME:-}" == "mac" ]] ||
  fail "OS_NAME が設定されていません。./setup.sh switch から実行してください"

REPO_DIR="$(dirname "${SCRIPT_DIR}")"

# OS 固有の処理 (check_nix / resolve_flake_attr / run_activation /
# post_activation_env / os_shell) を読み込む
# shellcheck disable=SC1091
source "${SCRIPT_DIR}/switch_hooks-${OS_NAME}.sh"
```

(b) ディレクトリ変数の置き換え:

```bash
DOTFILES_DIR="${OS_DIR}/dotfiles"   # 削除
NIX_DIR="${OS_DIR}/nix"             # → NIX_DIR="${REPO_DIR}/nix"
```

log_debug の `OS_DIR:` / `DOTFILES_DIR:` 行は `OS_NAME:` に差し替える。

(c) DotfilesLinker の実行部を common → OS の 2 回実行に置き換え:

```bash
echo
log_step "DotfilesLinker の実行"

if [[ "${dry_run}" == "true" ]] && ! command -v DotfilesLinker &>/dev/null; then
  log_warning "DotfilesLinker は nix 構成の適用後に利用可能になるためスキップします"
else
  command -v DotfilesLinker &>/dev/null ||
    fail "DotfilesLinker をPATHに反映できませんでした"
  for dotfiles_root in "${REPO_DIR}/dotfiles/common" "${REPO_DIR}/dotfiles/${OS_NAME}"; do
    log_info "DOTFILES_ROOT: ${dotfiles_root}"
    export DOTFILES_ROOT="${dotfiles_root}"
    if [[ "${dry_run}" == "true" ]]; then
      DotfilesLinker --dry-run
    else
      DotfilesLinker
    fi
  done
fi
```

## 手動フォローアップ (この計画のスコープ外、mac 実機が必要)

1. `monorepo` ブランチを push し、mac 実機で `./setup.sh prepare` (不要なら skip) → `./setup.sh switch` を検証
2. 問題なければ merge
3. GitHub 上で dotfiles-linux / dotfiles-mac をアーカイブ
4. update-flake-lock ワークフローの統合 (linux ジョブ + macos ランナーの darwin 検証ジョブの 2 job 構成) を別タスクで行う
